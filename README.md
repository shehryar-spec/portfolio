- 🎨 Modern dark theme with glass morphism, animated gradients, and particle background
- 📱 Fully responsive design
- ✨ Custom animated cursor, scroll progress bar, and smooth reveal animations
- 🚀 3D tilt effects on project cards
- 📊 Live project showcase with domain filtering
- 🌙 Custom intersection observer animations
- 📧 Contact links — Email, LinkedIn, GitHub
